Portfolio

Billie | LinkedIn | GitHub

This page acts as a portfolio for my work in the PP434 Data Visualisation course. I aim to produce 2 new charts per week, or more if required, and upload to my GitHub repository.

Week 1

In Week 1 I set up VS Code and GitHub, and published my first portfolio page. The two charts below were provided as starting examples. My task was to embed them into my own page, which involved linking each chart's Vega-Lite specification to a <figure> element on the page using a matching id.

Week 2

In Week 2 I moved from using given charts to building my own. The first chart started as an example from a Vega-Lite chart repository, which I adapted by changing the colours, width and other styling. For the second chart I used real data from the ONS (UK CPI rate 2015-2025). I cleaned the data in Excel, saved it as a CSV, uploaded it to GitHub, and then built a chart that pulls in that data through its raw URL.
